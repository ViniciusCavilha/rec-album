# Rec Álbum

Aplicativo Ionic/Vue para organizar uma coleção pessoal de álbuns musicais.

## Informações acadêmicas

- **Aluno:** Vinicius Souza
- **Curso:** Informática
- **Unidade curricular:** Codificar Aplicações para Dispositivos Móveis

## Projeto

O app oferece cadastro, login e uma área protegida em que cada usuário pode cadastrar álbuns com nome, artista, ano e músicas. Também permite consultar detalhes, favoritar e remover álbuns. Os dados são persistidos no `localStorage` e separados por usuário.

## Como rodar

Com Node.js 18 ou superior instalado:

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Tecnologias

Vue 3, TypeScript, Ionic, Capacitor e Vite.
